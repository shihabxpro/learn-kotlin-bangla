## 📖 প্রজেক্ট ওভারভিউ (Project Overview)

**Kotlin Journey** হলো বাংলা ভাষায় Kotlin প্রোগ্রামিং ভাষা শেখার একটি আধুনিক, সমৃদ্ধ ও আকর্ষণীয় ওয়েব প্ল্যাটফর্ম। যারা অ্যান্ড্রয়েড অ্যাপ ডেভেলপমেন্ট বা ব্যাকএন্ড ডেভেলপমেন্ট শিখতে চান, তাদের জন্য Kotlin-এর ফান্ডামেন্টালস থেকে শুরু করে অ্যাডভান্সড ও কনকারেন্সি (Coroutines) পর্যন্ত ধাপে ধাপে সাজানো হয়েছে।

প্রজেক্টটিতে প্রতিটি টপিকের গভীর ব্যাখ্যা, বাস্তব জীবনের অ্যানালজি, সাধারণ ভুল ও সমাধান, এবং ইন্টারঅ্যাক্টিভ কনটেইনার ভিজ্যুয়ালাইজার যুক্ত রয়েছে।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 🗺️ **সম্পূর্ণ রোডম্যাপ (Interactive Roadmap):** বিগিনার থেকে শুরু করে অ্যাডভান্সড পর্যন্ত সুনির্দিষ্ট মাইলস্টোনে বিভক্ত রোডম্যাপ।
- 💡 **সহজ বাংলা ব্যাখ্যা:** জটিল প্রোগ্রামিং কনসেপ্টগুলো খাঁটি ও সহজবোধ্য বাংলা ভাষায় ব্যাখ্যা করা।
- 🎨 **আকর্ষণীয় ডিজাইন ও ডার্ক থিম:** আধুনিক গ্লাস-মরফিজম ও আরামদায়ক ডার্ক থিমযুক্ত ইউজার ইন্টারফেস।
- 💻 **রিয়েল কোড সিনট্যাক্স হাইলাইটার:** কীওয়ার্ড, ডেটা টাইপ, মেথড, স্ট্রিং টেমপ্লেট ও অপারেটর আলাদা রঙে প্রদর্শিত।
- 📦 **ইন্টারঅ্যাক্টিভ মেমোরি সিমুলেশন:** `val` বনাম `var` মেমোরি পাত্র (Container) লাইভ বাটন প্রেস করে বোঝার ইন্টারঅ্যাক্টিভ টুল।
- ⚠️ **কমন মিস্টেক্স ও বেস্ট প্র্যাকটিস:** শিক্ষার্থীরা সচরাচর কোথায় ভুল করে এবং সেগুলোর সঠিক সমাধান কী তা হাইলাইট করা।
- 🏆 **প্র্যাকটিস টাস্ক ও আউটপুট প্রিভিউ:** প্রতিটি লেসনের শেষে নিজে নিজে অনুশীলন করার জন্য রিয়েল টাস্ক ও প্রত্যাশিত আউটপুট।
- 📱 **সম্পূর্ণ রেসপন্সিভ:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসেই মসৃণভাবে ব্যবহারযোগ্য।

## 🧭 কারিকুলাম ও রোডম্যাপ (Roadmap Modules)

| ধাপ | মডিউলের নাম | লেভেল | বিষয়বস্তু |
| :---: | :--- | :---: | :--- |
| **01** | **Fundamentals (মৌলিক ভিত্তি)** | বিগিনার | ভেরিয়েবল (`val`/`var`), ডেটা টাইপ, অপারেটর, ইনপুট-আউটপুট, স্ট্রিং টেমপ্লেট |
| **02** | **Control Flow (কন্ট্রোল ফ্লো)** | বিগিনার | `if-else`, আধুনিক `when` এক্সপ্রেশন, `for`, `while`, রেঞ্জ (`..`, `until`, `step`) |
| **03** | **Functions (ফাংশন)** | বিগিনার | Named & Default Arguments, Single-expression ফাংশন, Vararg, Lambdas |
| **04** | **Null Safety (নাল সেফটি)** | ইন্টারমিডিয়েট | Nullable Types (`?`), Safe Call (`?.`), Elvis (`?:`), Not-Null Assertion (`!!`) |
| **05** | **Collections (কালেকশনস)** | ইন্টারমিডিয়েট | List, Set, Map, Mutable বনাম Read-only, `filter`, `map`, `groupBy` ইত্যাদি |
| **06** | **OOP (অবজেক্ট ওরিয়েন্টেড)** | ইন্টারমিডিয়েট | Class, Constructor, Data Class, Inheritance, Interface, Abstract Class |
| **07** | **Advanced (অ্যাডভান্সড কনসেপ্ট)** | অ্যাডভান্সড | Extension Functions, Sealed Classes, Generics (`<T>`), Infix Function |
| **08** | **Coroutines (কনকারেন্সি)** | অ্যাডভান্সড | Asynchronous Programming, `suspend` fun, Dispatchers, Flow, Channels |

## 🚀 লোকাল মেশিনে রান করার নিয়ম (Getting Started)

খুব সহজেই প্রজেক্টটি আপনার লোকাল পিসিতে ক্লোন করে চালাতে পারেন:

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```

ব্রাউজারে গিয়ে ওপেন করুন: `http://localhost:3000` (বা টার্মিনালে দেখানো পোর্টে)।
