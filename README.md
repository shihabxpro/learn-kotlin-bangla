📖 About

Kotlin Journey হলো বাংলাভাষী শিক্ষার্থীদের জন্য তৈরি একটি interactive Kotlin learning platform।

এখানে Kotlin-এর basic fundamentals থেকে শুরু করে OOP, Collections, Advanced Concepts এবং Coroutines পর্যন্ত ধাপে ধাপে শেখানো হয়েছে।

প্রতিটি topic সহজ বাংলায় ব্যাখ্যা করা হয়েছে, যাতে programming-এ নতুনরাও সহজে বুঝতে পারে।

«💡 Learn Kotlin in Bangla — Step by Step, From Beginner to Advanced.»

🧭 Kotlin Roadmap

#| Module| Level| Topics
01| Fundamentals| 🟢 Beginner| Variables, Data Types, Operators, Input/Output
02| Control Flow| 🟢 Beginner| "if-else", "when", "for", "while", Ranges
03| Functions| 🟢 Beginner| Functions, Arguments, "vararg", Lambdas
04| Null Safety| 🔵 Intermediate| Nullable Types, "?.", "?:", "!!"
05| Collections| 🔵 Intermediate| List, Set, Map, "filter", "map", "groupBy"
06| OOP| 🔵 Intermediate| Class, Constructor, Inheritance, Interface
07| Advanced| 🟣 Advanced| Extension Functions, Generics, Sealed Classes
08| Coroutines| 🟣 Advanced| "suspend", Dispatchers, Flow, Channels
